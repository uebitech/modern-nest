# ADR 0001: Usar NestJS

## Status

Aceita.

## Contexto

O projeto precisa de uma API TypeScript organizada por módulos e com injeção de
dependências.

## Decisão

Usar NestJS como framework HTTP e de composição da aplicação.

## Consequências

A aplicação usa decorators, módulos, controllers, providers e lifecycle NestJS.
A equipe precisa seguir as convenções do framework.
