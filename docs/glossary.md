# Glossário

## NestJS

Framework Node.js para aplicações TypeScript modulares.

## Module

Unidade que agrupa controllers, providers, imports e exports.

## Controller

Classe que recebe requests e define rotas HTTP.

## Service

Provider que concentra operações e regras de negócio.

## Provider

Objeto gerenciado pelo container de injeção de dependências.

## Entity

Classe que representa uma tabela e suas colunas no ORM.

## Repository

Objeto que encapsula consultas e persistência de uma entity.

## DTO

Data Transfer Object; define dados que atravessam uma fronteira da aplicação.

## Decorator

Sintaxe que adiciona metadata ou comportamento a classes e membros.

## Guard

Componente que decide se uma request pode continuar.

## Middleware

Função executada antes do handler para preparar ou observar a request.

## Pipe

Componente que valida ou transforma argumentos.

## Interceptor

Componente que envolve a execução do handler antes e depois.

## Exception Filter

Componente que captura exceptions e formata respostas.

## TypeORM

ORM usado para mapear classes TypeScript para bancos relacionais.

## MariaDB

Banco relacional usado neste projeto.

## Migration

Alteração versionada e reproduzível do schema do banco.

## Docker

Tecnologia para empacotar e executar aplicações em containers.

## Docker Compose

Ferramenta para definir e executar múltiplos serviços relacionados.

## Healthcheck

Verificação automática de disponibilidade ou prontidão.

## JWT

JSON Web Token assinado usado para transportar claims de autenticação.

## CORS

Política que controla origens de navegador autorizadas a acessar a API.
